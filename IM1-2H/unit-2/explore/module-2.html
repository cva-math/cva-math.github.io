Shoes Off First

Most of the questions that matter in this unit run backwards — not what does this job pay? but what would I have to do to earn it? Running a rule backwards sounds like one move. It’s two, and the order they go in is the whole thing.

Build the undo. Let the check tell you.

What you just saw

You put your socks on, then your shoes. Taking them off, the shoes come first. The job’s rule multiplied by 6 and then added 12 — so running it backwards has to take the 12 off first, and only then divide. Undo in the order you read it and you divide the whole $90, including the $12 that was never per-delivery, and you get 3: a believable number that is simply wrong. The last thing done is the first thing undone.

The names for this, when you’re ready for them: subtracting undoes adding and dividing undoes multiplying, so each is the inverse operation of the other. Chain them in reverse order and you have the inverse of the whole rule: pay in, deliveries out. And the check you watched — run the answer forward and see if it lands on the number you started with — works on any inverse you ever find.

What you just saw

Every row of the log took 12 off and then divided by 6. The number at the start changed and the number at the end changed, and the two steps in the middle never did. So you don’t need to run the machine again for every shift — you can run it once on a letter that stands for any shift, and what comes out is the backward rule for all of them. And the machine answers honestly even when the job wouldn’t: it will hand you 6.33 deliveries, or a negative number, without complaint.

The name: write P for what the shift pays, run it through the two steps, and you get d = (P − 12) ÷ 6 — the inverse function of the job’s rule, P = 6d + 12. The parentheses are the order, written down: take the 12 off first. Finding it is the same algebra as solving the job’s rule for d. And the answers still have to make sense in the job. A delivery comes whole, so 6.33 means 7. Anything the $12 already covers means none.

Then The Card

One machine the page won’t build for you.

One step, run twice

A machine that undoes itself.

Run it once and your number changes. Run the very same machine again, and you’re back where you started — for every number. The machine that adds 3 isn’t one: its undo subtracts 3. Is there a machine that is its own undo?

Try some. If you find one, say what its step is, and why running it twice brings every number home.

Running a rule backwards isn’t one move. It’s every move, reversed — and the last thing done is the first thing undone.
